🚀 Curated AI & Automation Repositories

🛠️ Automação, Agentes & Orquestração

n8n

Plataforma de automação de workflows altamente extensível com suporte nativo a nós de IA.

Firecrawl

API de extração e conversão de páginas da web em Markdown para pipelines de RAG e agentes.

AutoGPT

Pioneiro na criação e execução de agentes autônomos para tarefas complexas e iterativas.

Dify

Framework para conectar agentes de IA à navegação web interativa diretamente no browser.

Interface drag-and-drop no-code/low-code para construir fluxos baseados em LangChain.

💻 Agentes de Código & Execução CLI

OpenHands

Agente autônomo capaz de escrever código, executar comandos de terminal e resolver tarefas de software.

Cline

Assistente autônomo de codificação para VS Code que cria/edita arquivos e executa comandos CLI.

Open Interpreter

Interface em linguagem natural para o terminal executar códigos em Python, JS e Shell no seu computador.

🏠 Infraestrutura & Execução de LLMs Locais

Ollama

Ferramenta leve para rodar e gerenciar LLMs open-source localmente via terminal ou API.

llama.cpp

Motor de inferência de alta performance em C/C++ otimizado para modelos de linguagem locais.

LocalAI

Alternativa self-hosted e drop-in compatível com a API da OpenAI para execução local.
