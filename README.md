# 🚀 Curated AI & Automation Repositories

Uma coleção selecionada dos repositórios open-source mais relevantes no ecossistema de Inteligência Artificial, automação de workflows, orquestração de agentes e execução local de LLMs.

---

## 🛠️ Automação, Agentes & Orquestração

* **[n8n](https://github.com/n8n-io/n8n)**
  Plataforma de automação de workflows altamente extensível com suporte nativo a nós de IA, permitindo integrar APIs, bancos de dados e LLMs em fluxos autônomos.
* **[Firecrawl](https://github.com/firecrawl/firecrawl)**
  API de extração e conversão de páginas da web em Markdown pronto para ser consumido por pipelines de RAG e agentes de IA.
* **[AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)**
  Um dos pioneiros na criação e execução de agentes autônomos de IA capazes de realizar tarefas complexas e iterativas de forma independente.
* **[Dify](https://github.com/langgenius/dify)**
  Plataforma completa de desenvolvimento de aplicações de IA (LLMOps) para criação de agentes, fluxos RAG e gerenciamento de prompts.
* **[Browser Use](https://github.com/browser-use/browser-use)**
  Framework para conectar agentes de IA à navegação web, permitindo automação interativa de tarefas diretamente no navegador.
* **[Flowise](https://github.com/FlowiseAI/Flowise)**
  Interface drag-and-drop no-code/low-code para construir fluxos de aplicações baseados em LangChain e IA Generativa.

---

## 💻 Agentes de Código & Execução CLI

* **[OpenHands](https://github.com/OpenHands/OpenHands)**
  Plataforma de desenvolvimento focada em agentes autônomos capazes de escrever código, executar comandos de terminal e resolver tarefas de engenharia de software (anteriormente conhecido como OpenDevin).
* **[Cline](https://github.com/cline/cline)**
  Assistente autônomo de codificação integrado ao VS Code que pode criar, editar arquivos e executar comandos de terminal com autorização do usuário.
* **[Open Interpreter](https://github.com/openinterpreter/open-interpreter)**
  Interface de linguagem natural para o terminal que permite a LLMs executar código Python, JavaScript e Shell diretamente na sua máquina local.

---

## 🏠 Infraestrutura & Execução de LLMs Locais

* **[Ollama](https://github.com/ollama/ollama)**
  Ferramenta leve e eficiente para baixar, configurar e executar LLMs open-source (como Llama 3, Mistral e Qwen) localmente via terminal ou API.
* **[llama.cpp](https://github.com/ggml-org/llama.cpp)**
  Motor de inferência de alta performance em C/C++ otimizado para a execução de modelos de linguagem em hardware de consumo.
* **[LocalAI](https://github.com/mudler/LocalAI)**
  Alternativa self-hosted e drop-in compatível com a API da OpenAI para executar LLMs, geração de imagem e áudio no seu próprio hardware.

---

## 💬 Interfaces de Usuário & Chat (UI/UX)

* **[Open WebUI](https://github.com/open-webui/open-webui)**
  Interface web auto-hospedada rica em recursos e amigável (estilo ChatGPT) projetada para funcionar integrada ao Ollama e APIs compatíveis.
* **[LobeHub](https://github.com/lobehub/lobehub-chat)**
  Framework de chat open-source com design moderno, suporte a plugins, multimídia e múltiplos provedores de LLM.
* **[AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)**
  Aplicação desktop/server completa para conversar com documentos (RAG), suportando múltiplos provedores de embedding e vetores sem vazamento de dados.
* **[LibreChat](https://github.com/LibreChat-AI/LibreChat)**
  Clone de código aberto do ChatGPT com suporte a múltiplos provedores, multimodalidade e gerenciamento avançado de conversas.
* **[Jan](https://github.com/janhq/jan)**
  Alternativa 100% offline ao ChatGPT que roda totalmente no computador, focada em privacidade e facilidade de uso.

---

## 📚 RAG & Tratamento de Documentos

* **[RAGFlow](https://github.com/infiniflow/ragflow)**
  Engine de RAG open-source baseada em compreensão profunda de documentos, otimizada para extração precisa de conhecimento em formatos estruturados e não estruturados.
* **[MarkItDown](https://github.com/microsoft/markitdown)**
  Utilitário da Microsoft para conversão rápida de diversos formatos de arquivo (PDF, docx, pptx, html) para Markdown formatado.

---

## 🎨 Imagem, Áudio & Multimídia

* **[ComfyUI](https://github.com/Comfy-Org/ComfyUI)**
  Interface modular baseada em nós para criação avançada e otimizada de pipelines de difusão de imagens (Stable Diffusion / FLUX).
* **[Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui)**
  A interface web clássica (AUTOMATIC1111) mais popular para geração e edição de imagens via Stable Diffusion.
* **[Fooocus](https://github.com/lllyasviel/Fooocus)**
  Ferramenta de geração de imagem focada em simplicidade e qualidade visual automatizada, inspirada no Midjourney.
* **[Whisper](https://github.com/openai/whisper)**
  Modelo de reconhecimento de voz e transcrição de áudio multilíngue de alta precisão desenvolvido pela OpenAI.
* **[GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)**
  Sistema avançado de clonagem de voz e conversão text-to-speech (TTS) com apenas 5 segundos de amostra de áudio.
* **[Presenton](https://github.com/presenton/presenton)**
  Ferramenta open-source para geração e estilização automatizada de apresentações de slides alimentada por IA.
